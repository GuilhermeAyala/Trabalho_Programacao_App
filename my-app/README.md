# Trabalho de Programação de App

Aplicação em React Native com Expo, criada para o trabalho final da matéria de Programação de App.

## Como executar

1. Instale as dependências:

   ```bash
   npm install
   ```

2. Inicie o projeto:

   ```bash
   npm start
   ```

## Estrutura

- `src/app`: telas e layouts do Expo Router.
- `src/components`: componentes reutilizáveis.
- `src/hooks`: hooks personalizados.
- `src/constants`: constantes da aplicação.
- `assets`: ícones e imagens usados pelo aplicativo.

A primeira tela está em `src/app/index.tsx`.
